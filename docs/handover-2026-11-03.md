## How the work runs (unchanged; see NOTES.md for the full routine)

- Every change under test goes behind a `?switch` (`core/fixes.ts`) with a `src/testlist.ts`
  entry; the owner tests on the phone; on a pass it becomes the default, the switch and old path
  deleted, proved SAME against a switch-on reference (`RAC3R_QUERY='x=1' node tools/simhash.mjs
  save` before, plain `simhash` after).
- Push: commit, `git push origin HEAD:refs/heads/foreman/<name>`, wait for the `verify` run
  (`gh run list -R staystale/Rac3r --branch foreman/<name> --workflow verify`), push to main,
  delete the branch, update the served clone with `git checkout --detach origin/main`. The
  `checks` workflow compares with the parent commit, so a default flip fails it on purpose; its
  menucheck step also times out on CI's slow runner (passes locally).
- `tools/menucheck.mjs` waits 600 ms between taps (a press blinks 160 ms, a new screen ignores
  taps for 350 ms).
- Measuring scripts written this session are in `tools/scratch` (gitignored, laptop only):
  `_mudpull2.mjs` (0-50 on dirt / mud / thick mud, GRADE= for a hill), `_mudhill.mjs` (the Rough
  Patch hills in game), `_resetcheck.mjs`, `_aicost.mjs` (AI frame cost), `_tyrestats.mjs`,
  `_launch.mjs`, `_pool.mjs` / `_puffwatch.mjs` (the puff pool), `_garageflow2.mjs`.
